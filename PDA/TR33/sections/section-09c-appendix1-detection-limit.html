9.3 Estimation of the Detection Limit 偵測極限之估計

原文內容 Original Text

Table 9.3-1 contains the results of an experiment set up to determine the LoD of the AMM/RMM, without making a direct comparison with the CMM. The data was collected for one type of microorganism or species with one suspension created and spiked with a known number of microorganisms that is close to the AMM/RMM's purported LoD (e.g., <10 cells). Five (5) additional suspensions, using different concentrations from the initial suspension, were created. From each suspension, twenty (20) samples were drawn and tested on the presence/absence with the AMM/RMM. The concentrations listed in Table 9.3-1 represent the expected average number of microorganisms present in the test sample.

Different statistical approaches exist for estimating the LoD based on the data in Table 9.3-1. The logistic regression approach with different risk curves and the most probable limit (MPL) is described here (12-15).

導師解析 Tutorial Commentary

核心概念解析 Key Concepts

Limit of Detection (LoD, 偵測極限): AMM/RMM 能以足夠信心（本節採 95% 機率）偵測到的最小微生物數。與 Section 9.2 不同，本節不需要 CMM 做為對照組——只需針對單一 AMM/RMM，用一支懸浮液配製出多個已知平均濃度的稀釋液，各測 20 個樣本，即可單獨估計該方法的 LoD。

實驗設計邏輯: 起始懸浮液濃度刻意設定接近方法「號稱」的 LoD（例如 <10 cells），再稀釋出 5 個不同濃度點，形成一條「濃度—陽性率」的劑量反應曲線（dose-response curve），這是後續 9.3.1 邏輯斯迴歸與 9.3.2 MPL 分析共同的資料基礎。

比喻說明 Analogy

這個實驗設計就像測試一支麥克風「最小能收到多小聲音」的靈敏度——你不會只測一種音量，而是準備從很小聲到中等音量的多個級距（本例 5 個濃度點），每個級距重複測試 20 次，記錄「聽得到」的次數比例。聲音（濃度）越小，聽到的比例（陽性率）自然越低；透過觀察這條「音量 vs. 聽到比例」的曲線，就能推算出麥克風真正的靈敏度極限，而不需要拿另一支麥克風來做比較。

重點提示 Key Notes

本節刻意強調「without making a direct comparison with the CMM（不需要與 CMM 直接比較）」——這與 Section 9.2 的非劣性檢定邏輯不同。9.3 節的目標是描述 AMM/RMM 本身的絕對偵測能力（一條劑量反應曲線），而非相對於傳統方法的「不劣於」宣稱。兩種驗證策略在法規對話中扮演不同角色，實務上常需搭配使用。

9.3.1 Logistic Regression Analysis 邏輯斯迴歸分析

原文內容 Original Text

The logistic regression approach models the positive rate as a function of concentration. Often the following relationship is proposed (12, 13): 

log( p_A / (1 − p_A) ) = α + β · log(λ)

Where:

p_A  =  positive rate for the AMM/RMM
λ    =  average number or concentration of microorganisms in the test samples
α    =  intercept
β    =  slope indicating how quickly the positive rate changes with the changes in
        log concentration log(λ)

The value log(pA/(1 − pA)) is called the "logit" of positive rate pA. The value exp{−α/β} is the concentration at which a positive rate of 50% is obtained.

This model assumes that the probability of a presence test for a blank test sample is equal to zero, since it forces the positive rate to zero when no microorganisms are present in the test sample. Additionally, the positive rate as a function of the log concentration has a nice S-shape (blue curve on the right of Figure 9.3.1-1) but, as the function of the concentration, the positive rate quickly rises to a high probability and then flattens (blue curve on the left in Figure 9.3.1-1). This latter curve may be considered as a function of the negative rate (i.e., one minus the positive rate), because the slow increase with decreasing concentration and rapid increase when the concentration reaches zero seems like an exponential function. This alternative model may be formulated as: 

log(1 − p_A) = −θ · λ

Where:

p_A  =  positive rate for the AMM/RMM
θ    =  detection proportion
λ    =  average number or concentration of microorganisms in the test samples

In this expression we only have a single parameter θ instead of the intercept α and slope β for the logistic regression analysis. In this exponential model, the positive rate would then be formulated as pA = 1 − exp{−θλ}, which resembles the function for the gMPN approach*. The red curves in Figure 9.3.1-1 show this alternative model and seems very close to the two-parameter logistic curve.

*Note: This gMPN-related curve has been shown in Figure 9.2.2-1 as well.

Figure 9.3.1-1: Visualization of the Positive Rate as Function of the Concentration (left) and Log Concentration (right)

Both curves in Figure 9.3.1-1 can be estimated on multi-concentration data using logistic regression analysis programmed in general-purpose statistical software but fitting the curve related to the gMPN approach requires a deeper understanding of the options for the logistic regression function. Thus, the two-parameter logistic function is more straightforward in practice and, therefore, easier to fit with general-purpose statistical software. Nevertheless, the gMPN-related curve has only one parameter and is therefore a simpler model, and it has a direct connection to the MPN approach, making it easier to determine the LoD.

Fitting both curves to the data in Table 9.3-1 results in the following parameter estimation with its asymptotic 95% confidence (an exact confidence interval does not exist): 

Logistic curve:      α = 0.707 (0.140, 1.275)   and   β = 1.746 (1.081, 2.412)
gMPN-related curve:  θ = 0.972 (0.673, 1.000)

The curves with the estimated parameters were already visualized in Figure 9.3.1-1. If the LoD is the smallest number of organisms in a test sample that can be detected with at least 95% probability, the fitted curves can be used to establish these limits.

The average concentration in test samples that can be detected with exactly 95% probability are given by: 

Logistic curve:      λ_LoD = exp(−α/β) · (19)^(1/β) = 3.60 (1.04, 6.16)
gMPN-related curve:  λ_LoD = −log(0.05) / θ         = 3.08 (2.13, 4.03)

These limits are not the LoD, but an average concentration in test samples, which is typically an overestimation of the LoD. An illustration of this is to assume that test samples with an average concentration of 3.6 CFU's per test sample have been created. If, additionally, the distribution of the number of microorganisms in the test samples equals a Poisson distribution (with mean 3.6), 2.73% of the test samples will be blank test samples and 97.27% of the test samples contain one or more microorganisms. Something similar has already been visualized in Figure 9.2-1, but with an average number of 2 CFUs per test sample. If, in addition, the AMM/RMM does not produce any false positives, all blank samples will be tested as absent, which is approximately 2.7%. To obtain a 95% probability for all test samples, the AMM/RMM should produce a presence test for almost all test samples that do contain at least one microorganism. Thus, the λLoD = 3.60 implies that the LoD is most likely equal to one. This conclusion is supported by the gMPN-related curve, because the parameter θ represents the detection probability, which is the probability of a positive test for a test sample containing a single microorganism. The parameter θ is estimated at θ = 0.972, which is above 95%, indicating that the LoD is one. This can be confirmed by calculating the cumulative 5% (0.05) probability for a Poisson distribution plot with a mean value = 3.60 (i.e., adding the individual probabilities and reporting the first number in the plot that passes the cumulative 5% threshold).

導師解析 Tutorial Commentary

核心概念解析 Key Concepts

Logistic Regression（邏輯斯迴歸）與 Logit（對數勝算比）: 邏輯斯迴歸是統計學中用來描述「二元結果（陽性/陰性）機率如何隨連續變數變化」的標準工具。logit = log(p/(1−p)) 把 0～1 之間的機率轉換成 −∞～+∞ 的線性尺度，使其能以簡單的直線方程式 α + β·log(λ) 描述，這是為何要用 log(λ) 而非 λ 本身作為自變數的原因——濃度與陽性率的關係在對數尺度下呈現漂亮的 S 形曲線。

兩參數邏輯斯模型 vs. 單參數 gMPN 相關指數模型: 前者（α、β）較有彈性、適配度較佳，是大多數統計軟體的預設選項；後者（θ）只有一個參數，數學上與 gMPN 方法（Section 9.2.3）直接相通，θ 本身就是 detection proportion（偵測比例），因此更容易直接轉換為 LoD 的結論，但需要對邏輯斯迴歸函數的選項有更深入的理解才能正確擬合。

從 λLoD 到 LoD 的推理: λLoD（3.60 或 3.08）是「平均濃度」，並非真正的 LoD（最小可偵測微生物數，通常是整數如 1）。原文示範了一個重要的推理鏈：假設平均濃度 3.6 時，Poisson 分布顯示僅 2.73% 樣本為完全空白，其餘 97.27% 至少含 1 顆微生物；若方法無偽陽性，則所有空白樣本都會被判為陰性（約 2.7%），恰好對應到 95% 的偵測機率門檻——因此推論 LoD = 1。

比喻說明 Analogy

把兩參數邏輯斯模型與單參數 gMPN 模型的關係想像成「訂製西裝」與「均碼西裝」：兩參數模型有 α（起始位置）與 β（反應速度）兩個可調參數，就像量身訂做，能更精準貼合各種形狀的資料曲線；單參數 gMPN 模型只有 θ 一個旋鈕，比較像均碼西裝，適配度可能略遜一籌，但穿脫（換算 LoD、與 gMPN／MPN 理論串接）方便許多，也更容易讓非統計背景的微生物學家直接解讀「θ 值多高代表偵測能力多好」。

重點提示 Key Notes

本節反覆強調一個容易被誤解的關鍵區別：λLoD ≠ LoD。λLoD 是「在 95% 機率下可被偵測到的平均濃度」，本質上是連續量的估計值（3.60 或 3.08），而 LoD 是「最小可偵測的微生物『個數』」，通常必須是整數。原文明確指出 λLoD 「typically an overestimation of the LoD」——也就是說，若直接把 3.6 或 3.08 當作 LoD 使用，會顯著高估方法所需的最低微生物數，因此必須透過 Poisson 分布反推，才能得出「LoD 最可能等於 1」的合理結論。撰寫驗證報告時，切勿混淆這兩個數字。

兩條曲線（邏輯斯 vs. gMPN 相關指數模型）給出的 λLoD 略有差異（3.60 vs. 3.08），但推論出的 LoD 結論一致（皆為 1）——這說明在資料品質良好時，兩種建模選擇對最終「LoD 是多少」的實務結論通常是穩健的（robust），差異主要反映在精確的信賴區間寬度上。

公式與計算 Formula

模型一：兩參數邏輯斯迴歸（Logit 模型）

log( p_A / (1 − p_A) ) = α + β · log(λ)
  • p_A = AMM/RMM 的陽性率
  • λ = 測試樣本中微生物之平均數量（濃度）
  • α = 截距；β = 斜率（陽性率隨 log 濃度變化的速度）
  • 50% 陽性率對應之濃度 = exp{−α/β}

模型二：單參數 gMPN 相關指數模型

log(1 − p_A) = −θ · λ        ⟺        p_A = 1 − exp{−θλ}
  • θ = detection proportion（偵測比例，等同 gMPN 分析中的 θ）

代入 Table 9.3-1 資料之估計結果：

Logistic:  α = 0.707 (0.140, 1.275)    β = 1.746 (1.081, 2.412)
gMPN-related:  θ = 0.972 (0.673, 1.000)

95% 偵測機率對應之平均濃度 λ_LoD：

Logistic curve:      λ_LoD = exp(−α/β) · (19)^(1/β) = 3.60 (1.04, 6.16)
gMPN-related curve:  λ_LoD = −log(0.05) / θ         = 3.08 (2.13, 4.03)

其中 19 = (1 − 0.95)/0.05⁻¹ 的等價形式，源自 95% 偵測機率反推濃度時的代數化簡；−log(0.05) ≈ 2.996，是 95% 累積機率對應的自然對數常數。兩式皆為求解「使陽性率達 95% 的濃度」而反推 λ 的公式。

實務應用 Practical Application

假設 Amaran 為某客戶的 AMM/RMM 平台執行 LoD 驗證研究，取得類似 Table 9.3-1 的 5 個濃度點資料。若團隊具備一般統計軟體（Minitab、R）但無專屬微生物統計工具，建議優先使用兩參數邏輯斯迴歸（因為大多數軟體皆內建 logistic regression 功能，且更容易擬合），再以 λLoD 搭配 Poisson 分布反推整數 LoD 結論；若同時具備能力驗算 gMPN 相關指數模型，可將其作為交叉驗證（cross-check），若兩模型給出一致的 LoD 結論，驗證報告的說服力將顯著提升，也更能承受稽核方對統計方法選擇的質疑。

9.3.2 Most-Probable Limit Analysis 最可能極限（MPL）分析

原文內容 Original Text

The analyses so far have made use of statistical models where presence tests occur with a certain probability. Although these models are reasonable statistical models, the mechanism of detection may also be deterministic. This means that all test samples with a number of microorganisms below the LoD will be tested negatively with 100% certainty, while test samples containing a number of microorganisms equal to or greater than the LoD will test positive with 100% certainty. This model has been described in literature and has been used for estimation of the LoD of AMM/RMMs. It is referred to as the MPL and extends the MPN approach in a different way. The MPN approach assumes that the LoD is equal to one and then provides an estimate of the number of organisms in a suspension using a serial-dilution experiment. The MPL approach assumes that the LoD is equal to an unknown value L and estimates both the LoD and the number of microorganisms in the suspension (14, 15). The MPL approach is programmed in the specialized software TriMSA and can be programmed in SAS® and [R]. Applying the MPL approach to the data in Table 9.2.5-4, an estimate of the LoD of L = 1 with 95% confidence interval of [1, 2] and an estimate of the number of microorganisms in the initial suspension of MPN = 87 with 95% confidence interval of [56, 126] is obtained. If the LoD was equal to two, the MPN estimate would become MPN = 197 [160, 235]. The MPL approach applied to the data in Table 9.2.5-4, shows that the LoD is either one or two.

導師解析 Tutorial Commentary

核心概念解析 Key Concepts

Deterministic（確定性）模型 vs. 機率性模型: 9.3.1 的邏輯斯迴歸與 gMPN 相關指數模型都是「機率性」模型——即使樣本含有微生物，仍以某個機率（而非 100%）呈現陽性。MPL 則假設偵測機制是「確定性」的開關：只要樣本中微生物數 < LoD，必定測得陰性；只要 ≥ LoD，必定測得陽性，中間沒有模糊地帶。

Most-Probable Limit (MPL, 最可能極限): 傳統 MPN 方法「假設 LoD = 1」（即只要有 1 顆微生物就必然偵測到），再用序列稀釋實驗回推懸浮液中的微生物數。MPL 則反過來——把 LoD 本身視為未知數 L，與懸浮液中微生物數一起同時估計，是 MPN 概念的延伸與推廣。

估計結果的雙重性: 本例 MPL 分析同時給出兩組可能解：LoD = 1 時 MPN = 87 [56, 126]；LoD = 2 時 MPN = 197 [160, 235]。兩者皆為資料可支持的合理解，顯示 MPL 分析的結論有時需要搭配專業判斷（例如生物學上合理性）才能收斂到單一結論。

比喻說明 Analogy

MPL 與機率模型的差異，好比「感應式門鎖」與「機率式門鎖」的對比：機率式門鎖（邏輯斯/gMPN 模型）即使刷對卡片，仍有一定機率「刷不開」，卡片權限值越高、開門機率越高，但沒有絕對保證；感應式門鎖（MPL）則是非黑即白——只要卡片權限達到門檻 L，保證 100% 開門，未達門檻則保證 100% 打不開，門檻本身（L）才是待確認的未知數。MPL 分析要做的，就是同時猜出「門檻設在哪」以及「原本有多少張卡片」。

重點提示 Key Notes

原文引用之疑義提醒：原文此處寫作「Applying the MPL approach to the data in Table 9.2.5-4」，並二度重複此引用。惟 Table 9.2.5-4 在本附錄中實為 Section 9.2.5 之「Critical Values Rejecting Homogeneity（拒絕同質性之臨界值表，Cm、Pm 值）」，與此處 LoD/MPN 之 MPL 分析內容並無直接關聯，數值本身應源自 Table 9.3-1 的多濃度序列資料。此處為忠實轉錄原文之交叉引用標號，建議讀者在引用本節數據進行內部驗證時，以貴公司實際持有之官方版本或後續勘誤（errata）為準，勿逕自沿用此處編號進行二次查證。

MPL 分析同時給出 LoD=1 與 LoD=2 兩種情境下的 MPN 估計值，且兩者信賴區間並未明顯重疊（[56,126] vs. [160,235]）——這代表「LoD 究竟是 1 還是 2」對於推算懸浮液真實微生物濃度有實質影響，不能隨意假設。實務上應優先參考該物種的生物學特性與方法原理（例如該 AMM/RMM 技術對單一細胞的偵測能力）來判斷哪一個 LoD 值更合理，而非僅憑統計配適度選擇。

公式與計算 Formula

MPL 的確定性偵測模型（概念表示）：

若樣本中微生物數 x < L   →   偵測結果 = 陰性（機率 = 100%）
若樣本中微生物數 x ≥ L   →   偵測結果 = 陽性（機率 = 100%）
  • L = 未知的偵測極限（LoD），與傳統 MPN 假設 L = 1 不同，MPL 將 L 視為待估參數
  • MPN（最可能數）= 懸浮液中微生物濃度之估計值，與 L 一併由序列稀釋資料聯合估計

本例分析結果：

若 L = 1：  MPN = 87   95% CI [56, 126]
若 L = 2：  MPN = 197  95% CI [160, 235]

MPL 分析屬於聯合估計（joint estimation）問題，無簡單手算公式，須仰賴專用軟體 TriMSA，或以 SAS®／R 程式化實作。

實務應用 Practical Application

若 Amaran 團隊評估一款宣稱可偵測「單一細胞（single-cell detection）」技術原理的 AMM/RMM，MPL 分析特別適合用來交叉驗證該宣稱：若 MPL 估計出的 LoD 落在 [1, 2] 區間且與 9.3.1 邏輯斯迴歸的結論（LoD = 1）一致，即可提供更堅實的多方法交叉證據支持驗證報告；反之，若團隊沒有 SAS/R 程式撰寫能力，可優先以 9.3.1 的邏輯斯迴歸／gMPN 相關指數模型作為主要分析路徑，並在報告中註明 MPL 為文獻建議之替代驗證方式，留待未來有專用軟體資源時補做交叉確認。

本節重點回顧 Section Summary

  • Section 9.3 提供一種「不需與 CMM 比較」的 LoD 估計途徑——僅以單一 AMM/RMM 對多個已知濃度懸浮液進行序列測試（Table 9.3-1），建立劑量反應資料
  • 9.3.1 邏輯斯迴歸分析提供兩種風險曲線：兩參數邏輯斯模型（α、β，較有彈性、易於一般軟體擬合）與單參數 gMPN 相關指數模型（θ，與 gMPN 方法直接相通、更易換算 LoD）
  • 關鍵區別：λLoD（95% 偵測機率對應之平均濃度）並非真正的 LoD，通常會高估 LoD；須搭配 Poisson 分布反推，才能得出「LoD 最可能為整數 1」的結論
  • 9.3.2 Most-Probable Limit (MPL) 分析改採確定性偵測模型，將 LoD（L）本身視為未知參數，與懸浮液微生物濃度（MPN）聯合估計，是 MPN 方法的延伸
  • MPL 分析依賴專用軟體（TriMSA、SAS、R），且可能對不同 L 假設給出不同的 MPN 解，需搭配生物學判斷收斂結論；邏輯斯迴歸與 MPL 可交叉驗證，強化 LoD 驗證報告的說服力
