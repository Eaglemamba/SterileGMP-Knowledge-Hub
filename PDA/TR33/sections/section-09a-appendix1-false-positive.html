The content provided in Section 9.0 (Appendix 1) through Section 11.0 (Appendix 3) has been written in a manner that a microbiologist or an analysist with similar training would be able to understand the fundamental (statistical) concepts described. However, stakeholders may want to engage the expertise of a statistician to ensure the recommendations in these sections are appropriately executed.

Section 9.0 (Appendix 1) and Section 10.0 (Appendix 2) provide several acceptable statistical analyses for the validation of alternative qualitative and quantitative microbiological methods, respectively, while Section 11.0 (Appendix 3) focuses on additional considerations for non-colony forming units (CFU) qualitative and quantitative alternative/rapid microbiological methods (AMM/RMMs). Since these methods are presented only as examples, the stakeholder is responsible for selecting the most appropriate statistical analyses to use based on the data to be analyzed and the validation criteria being assessed. 核心概念解析 Key Concepts

False-Positive Rate (偽陽性率): 對已知不含活菌的空白樣本（blank samples）進行測試時，AMM/RMM 錯誤判讀為「陽性」的比例。這是 method suitability（方法適用性）研究的核心指標之一，直接反映方法的特異性（specificity）。

Blank Samples (空白樣本): 經確認不含活性微生物的對照樣本，用於評估方法本身的背景干擾訊號（background interference signal），而非用於評估偵測能力。

比喻說明 Analogy

偽陽性率的概念就像機場的金屬探測門——即使沒有攜帶任何違禁品的旅客通過，探測門偶爾仍可能因為皮帶扣、拉鍊而「誤鳴」。這種誤鳴率必須被量化並控制在可接受範圍內，而非要求「零誤鳴」，因為過度追求零誤鳴（極高靈敏度）反而可能犧牲對真正違禁品的偵測能力。

重點提示 Key Notes

9.1.1 Estimation and Confidence Intervals 估計值與信賴區間

原文內容 Original Text

Using the data in Table 9.1-1, the false-positive rate of the AMM/RMM, denoted by pA, is estimated as 0.05 or 5% (i.e., 1 positive/20 samples). This false-positive rate is based on only one experiment using 20 test samples. However, if the same experiment is repeated multiple times, it may result in a different, but valid, false-positive rate for each repeated experiment. A 95% confidence interval can quantify the range of valid estimates without having to repeat the experiments. In other words, the interpretation of the interval is a range of false positives that captures the true false-positive rate of the AMM/RMM with 95% confidence. The smaller the experiment or the higher the confidence level, the wider the confidence interval. If the goal was to obtain the absolute true false-positive rate with 100% confidence, an unrealistically large experiment would need to be conducted. This is why the use of an appropriate confidence interval, such as 95%, is more practical and acceptable.

Many different methods exist for constructing a confidence interval for analyzing proportions (1). The simplest 95% confidence interval is the asymptotic or Wald confidence interval, which is based on a normal approximation and calculated using the following formula: 

p_A ± 1.96 × sqrt( p_A (1 − p_A) / n )

Where:

n  =  number of samples tested (from Table 9.1-1, n = 20)

Using the formula above, the asymptotic 95% confidence interval for the false-positive rate based on the 20 samples is then estimated as (0, 0.146). Because the lower value of the interval was estimated below zero, the result was truncated to zero, since negative false-positive rates do not exist. The asymptotic 95% confidence interval indicates that the true false-positive rate of the AMM/RMM, when 20 samples are tested, lies between 0% and 14.6%, with 95% confidence.

One limitation in using the asymptotic confidence interval is that the number of samples tested should be above, for example, 50, and the number of events (here defined by the number of positive test samples) should not be close to/not approaching zero, for example, above 5. Because the example in Table 9.1-1 used 20 samples and the number of positive test samples was one, it would be more appropriate to use an alternative confidence interval known as the exact or Clopper-Pearson confidence interval (1), which is better suited for a smaller number of samples and low number of events. This interval is based on a binomial distribution (instead of a normal distribution for the asymptotic confidence interval), but the mathematical expression is far more complicated.

General-purpose statistical software packages can easily perform the exact confidence interval. Using the data in Table 9.1-1, the confidence interval becomes (0.001, 0.249). Thus, the exact 95% confidence interval implies that the true false-positive rate of the AMM/RMM lies between 0.1% and 24.9%, with 95% confidence. Due to the limitations of the asymptotic confidence interval, using the exact confidence interval when estimating a false-positive rate is recommended.

導師解析 Tutorial Commentary

核心概念解析 Key Concepts

Point Estimate（點估計）vs. Confidence Interval（信賴區間, CI）: 1/20 = 5% 只是「這一次實驗」觀察到的點估計值；若重複實驗，每次都可能得到不同但同樣有效的偽陽性率。95% CI 的作用，是不必真的重複實驗，就能用統計理論量化「真實偽陽性率」最可能落在的範圍。

Asymptotic / Wald CI（漸近／Wald 信賴區間）: 以常態分布（normal approximation）近似二項分布所建構的信賴區間，公式簡單、可手算，但在小樣本或極端比例（接近 0 或 1）時準確度不佳。

Exact / Clopper-Pearson CI（精確／Clopper-Pearson 信賴區間）: 直接以二項分布（binomial distribution）為基礎推導，公式複雜但在小樣本情境下更為準確，是 TR 33 推薦的預設方法。

比喻說明 Analogy

信賴區間就像天氣預報的「降雨機率區間」——氣象局不會說「明天絕對會下雨」，而是說「明天降雨機率的合理範圍是 0%–14.6%（95% 信心）」。實驗次數越少（樣本數越小）或要求的信心程度越高，這個範圍就必須越寬，才能涵蓋各種可能的真實情況；反之，若堅持要 100% 確定真實值，就必須做近乎無限大的實驗，這在現實中不可行。

Wald CI 與 Exact CI 的差異，好比用「捲尺目測」與「雷射測距儀」量測一段極短的距離：捲尺（Wald，常態近似）在測量大範圍距離時夠用又快速，但測量極短距離（小樣本、事件數趨近於零）時誤差比例會被放大甚至出現負值（如本例下限低於 0，需要截斷為 0）；雷射測距儀（Exact，二項分布）雖然計算更複雜，但在極短距離下依然準確可靠。

重點提示 Key Notes

Wald CI 出現「下限為負」的現象（本例中下限需截斷為 0），正是其在小樣本、低事件數情境下失效的典型徵兆。TR 33 明確指出：樣本數應大於約 50、且陽性事件數應大於約 5，Wald CI 才算適用；本例僅 20 個樣本、1 個陽性事件，遠低於此門檻，因此 Wald 的 (0, 0.146) 區間不應作為最終驗證依據。

比較兩種區間：Wald 給出 (0, 0.146)，Exact 給出 (0.001, 0.249)——Exact 區間的上限明顯更寬（24.9% vs 14.6%），代表 Wald 低估了不確定性。若稽核單位或客戶依賴較窄的 Wald 區間做決策，可能對方法的實際偽陽性風險過度樂觀。TR 33 建議：估計偽陽性率時應優先採用 Exact CI，而非 Wald CI。

公式與計算 Formula

Asymptotic (Wald) 95% Confidence Interval：

p_A ± 1.96 × sqrt( p_A (1 − p_A) / n )

變數定義：

  • p_A = AMM/RMM 的偽陽性率（本例 = 1/20 = 0.05）
  • n = 測試樣本數（本例 = 20）
  • 1.96 = 標準常態分布對應 95% 信心水準的臨界值

代入計算： 0.05 ± 1.96 × sqrt(0.05 × 0.95 / 20) = 0.05 ± 0.0956 → 下限為負，截斷為 0 → 區間 = (0, 0.146)

Exact (Clopper-Pearson) 95% Confidence Interval：基於二項分布之精確反函數推導，公式複雜、不建議手算，須以統計軟體（Minitab、R、SAS 等）計算。本例結果為 (0.001, 0.249)。

實務應用 Practical Application

假設 Amaran 為某客戶執行一款 AMM/RMM 快速無菌測試平台的方法適用性研究，測試 20 個空白樣本，其中 1 個呈陽性。若僅以 Wald CI 計算並向客戶回報「偽陽性率上限為 14.6%」，此數字可能低估真實風險；正確做法應改用 Exact CI 回報「上限為 24.9%」，並在驗證報告中明確說明選擇 Exact CI 而非 Wald CI 的統計理由（樣本數與事件數皆低於 Wald 適用門檻），以避免稽核時被要求重新分析。

重點提示 Key Notes

Table 9.1.2-1 有一個關鍵前提：「when the experiment does not contain any positive results（假設實驗全數呈陰性）」。一旦出現任何一個陽性結果，UCL 就會顯著上升（如 Section 9.1.1 中 20 個樣本、1 個陽性的 Exact CI 上限是 24.9%，遠高於全陰性時 20 個樣本對應的 13.9%）。規劃驗證方案樣本數時，務必以「最壞情境（可能出現 1 次陽性）」預留緩衝，而非僅套用全陰性情境的樣本數。

原文提供的實例極具參考價值：若要證明偽陽性率低於 1%（95% 信心），需測試 300 個空白樣本且全數陰性；若僅測試 30 個樣本且全陰性，則偽陽性率上限僅能宣稱不高於 9.5%。這對規劃驗證資源（檢體量、時程、成本）有直接的商業影響——越嚴格的偽陽性率宣稱，需要指數級增加的樣本投入。

公式與計算 Formula

給定目標偽陽性率上限 p，反推所需最小樣本數 n（假設全部樣本皆為陰性）：

n ≥ log(0.05) / log(1 − p)

變數定義：

  • p = 可接受的最大偽陽性率（例如欲宣稱 <1% 則 p = 0.01）
  • n = 需測試且全數為陰性的最小樣本數
  • log = 自然對數（如 Table 9.0-1 所定義）
  • 此公式的信心水準固定為 95%（對應 log(0.05) 中的 0.05 = 1 − 0.95）

反向公式——已知樣本數 n，回推可宣稱的最大偽陽性率上限：

Maximum allowable false-positive rate = 1 − (0.05)^(1/n)   (with 95% confidence)

範例驗算：若欲證明偽陽性率 <1%（p = 0.01），代入 n ≥ log(0.05)/log(0.99) ≈ 298.1 → 取整數並依 Table 9.1.2-1 對照，需 n = 300 個樣本且全數陰性。反向驗證：n = 30 時，1 − (0.05)^(1/30) ≈ 9.5%，與表列數值一致。

實務應用 Practical Application

假設某客戶要求 Amaran 的 AMM/RMM 平台必須證明偽陽性率低於 2%（95% 信心）。以公式反推：n ≥ log(0.05)/log(0.98) ≈ 148.3，故需準備至少 149 個空白樣本並確保全數陰性。若實驗室僅有 30 個空白檢體可用，只能宣稱偽陽性率不高於 9.5%——此時應提前與客戶溝通樣本數與可宣稱指標之間的統計限制，避免驗證計畫書送審後才發現無法達成原訂目標。

本節重點回顧 Section Summary

  • Appendix 1（Section 9.0-11.0）是 TR 33 本文統計建議的數學後盾，提供公式、範例數據與軟體對照，讓微生物學家在必要時可諮詢統計師以正確執行分析
  • Table 9.0-1 建立了貫穿整份附錄的統一符號系統（λ、p、θ、R、LCL/UCL、n、m 等），是閱讀 Section 9.1-11.0 各項統計方法的必備基礎
  • False-positive rate（偽陽性率）以獨立空白樣本的陽性事件比例估計，並非追求「零偽陽性」，而是量化並控制在可接受範圍內
  • 估計偽陽性率的 95% 信賴區間有兩種主要方法：Asymptotic (Wald) CI 公式簡單但在小樣本/低事件數時失準；Exact (Clopper-Pearson) CI 較準確、為 TR 33 建議的預設做法
  • 信賴區間寬度與樣本數呈反向關係——欲宣稱更低的偽陽性率上限，需要以 n ≥ log(0.05)/log(1−p) 計算出遠更大的樣本數（如 <1% 需 300 個全陰性樣本）
  • 樣本數規劃應以「可能出現陽性事件」的情境預留緩衝，而非僅套用 Table 9.1.2-1 假設「全數陰性」的最小樣本數
