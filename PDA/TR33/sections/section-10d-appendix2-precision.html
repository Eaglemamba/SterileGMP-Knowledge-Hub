10.4 Precision 精密度

原文內容 Original Text

For the validation of analytical measurement systems, precision is quantified by two measures: a relative standard deviation for repeatability and a relative standard deviation for intermediate precision. Repeatability quantifies within run variability (i.e., variability in enumerations under identical circumstances), and intermediate precision quantifies the sum of within and between run variability (i.e., variation in enumerations under routine varying conditions).

The analytical run is determined by factors that can change (e.g., analysts, test days, different instruments) every time a new set of enumerations is collected. The standard data-analytic approach to calculate these two relative standard deviations for the measures of precision is analysis of variance (ANOVA). For the estimation of the measures of precision, ANOVA does not make any distributional assumptions, but it often requires normality assumptions if additional features (e.g., confidence intervals, hypothesis testing for run variability) are being used with ANOVA. For validation of microbiological methods, it is common to follow the experimental setup of analytical measurement systems and apply ANOVA to quantify the within and between run variability. This approach is demonstrated in Section 10.4.1 using the data from Table 10.4-1. The run structure of the precision experiment is formed by the combinations of analysts and days (thus eight (8) runs in total).

See Table 10.4-1 below.

Although ANOVA can quantify variability within and between runs without making any distributional assumptions, there are considerations when the counts would follow a Poisson distribution. The Poisson distribution has only one parameter λ that quantifies both the mean value and the variance of the counts, and this fixes the value for the relative standard deviation to 100%/√λ (when replicated counts are collected at the same concentration). This value of relative standard deviation of the Poisson distribution is depicted in Figure 10.4-1, which shows that the relative standard deviation becomes small only when the mean value gets large. The relative standard deviation is never smaller than 10% for mean counts below 100 CFU. Thus, for mean counts less than 100 CFU, repeatability that is (much) less than 10% is not expected to be found when the counts follow a Poisson distribution and replicates are collected from different samples.

Figure 10.4-1: Visualization of the Relative Standard Deviation of a Poisson Distribution

In case the counts within runs (i.e., multiple enumerations from the same diluted suspension) follow a Poisson distribution, the relative standard deviation can be estimated by using the mean value of the counts instead of using ANOVA, which would estimate a separate variance parameter. In such situations, where the counts within runs follow a Poisson distribution, it would be better to analyze the precision experiment with a generalized linear mixed-effects model (GLMM) using the Poisson distribution. The repeatability is then determined by the estimated Poisson distribution, while the run-to-run variability is separately modeled with a latent variable that varies with the runs. This approach is illustrated in Section 10.4.2.

In the validation experiment for precision represented in Table 10.4-1, samples have been created at approximately the same spiked level for each day and each analyst. Precision experiments are often conducted this way, but typically at two or more spiked levels, to be able to quantify the precision at different microbial concentrations. At each spiked level, the data could be analyzed as demonstrated here, but there would also be options to analyze the full data simultaneously with ANOVA and GLMM.

The choice between ANOVA and GLMM depends mostly on a violation of using the Poisson distribution. If it appears that the counts at each run follow a Poisson distribution, the GLMM is preferred; however, when the variances of the counts within runs deviates (either larger or smaller) from the mean counts, the ANOVA approach may be preferred over the GLMM approach based on Poisson. This is similar to the approach for calculating accuracy at each concentration, where the choice was between a Poisson or a normal distribution (see Section 10.1.1 and Section 10.1.3).

導師解析 Tutorial Commentary

核心概念解析 Key Concepts

Repeatability（重複性）：同一分析人員、同一天、同一儀器下重複測量的變異，只反映「run 內」（within-run）雜訊，是方法本身「手夠不夠穩」的量尺。

Intermediate Precision（中間精密度）：不同分析人員、不同天所產生的總變異，等於「run 內 + run 間」變異的總和，反映方法在「日常變動條件」下能否維持一致結果——這才是實驗室日常放行時真正會遇到的變異來源。

ANOVA（變異數分析）：不需假設分布即可把總變異拆解成 MS_W（run 內均方）與 MS_B（run 間均方）兩塊，是精密度驗證的標準統計工具。

比喻說明 Analogy

把精密度驗證想像成評估一家連鎖手搖飲店的「甜度一致性」：Repeatability 就像同一位店員、同一台機器，連續搖十杯飲料的甜度差異；Intermediate Precision 則是把「不同分店、不同店員、不同天」都算進去的總差異。若只看單一店員的表現（Repeatability）很穩，但换店員、換分店後差異暴增，代表你需要更嚴謹的 SOP 或設備校正，而不是只信任單一店員的手感。

重點提示 Key Notes

Poisson 分布有一個關鍵限制：其 RSD 固定為 100%/√λ，也就是說平均菌落數（λ）越低，RSD 天生就會越大——在 100 CFU 以下，RSD 永遠不會小於 10%。這代表如果驗證數據在低濃度區間出現「異常漂亮」的低 RSD（遠低於 10%），品保人員反而應該懷疑數據是否真的符合 Poisson 假設，而非直接視為方法優異的證據。這是 Figure 10.4-1 給出的重要警訊曲線。

公式與計算 Formula

Poisson 分布的相對標準差（RSD）：

RSD(%) = 100% / √λ

變數定義：

  • λ = Poisson 分布之平均值（同時也是其變異數），對應平均菌落數（mean CFU）
  • 此關係僅在「相同濃度下的重複計數」情境下成立

例如 λ = 68 時，RSD ≈ 100/√68 ≈ 12.1%——這也是後面 10.4.2 節 GLMM 分析實際算出之 Repeatability（12.09%）幾乎完全吻合 Poisson 理論值的原因。

10.4.1 Analysis of Variance for Precision 精密度之變異數分析法

原文內容 Original Text

The ANOVA approach calculates the mean squares for within and between runs, denoted here by MS_W and MS_B, respectively. Any general-purpose statistical software package can determine these statistics from the data presented in Table 10.4-1. The mean square for the within-run variability (MS_W) is a direct estimate of the variance component (σ²_W) for the replicates within each run (as was used for linearity and the LoQ from the weighted linear regression analysis). The assumption is that this variance is the same for each run produced with the microbiological method. The mean square for the between-run variability (MS_B) is an estimate of:

n·σ²_B + σ²_W

Where:

  • σ²_B = variance component for the between-run variability
  • σ²_W = variance component for the within-run variability
  • n = number of replicates in each run

When the number of replicates vary from run-to-run, the MS_B estimates:

c·σ²_B + σ²_W

Where: c = a function of the different sample sizes in the runs (17).

Furthermore, if the software package has the option to choose a random effects model, the two variance components will be estimated directly.

The two measures of precision, repeatability and intermediate precision, are now defined by:

Repeatability: RSD_R(%) = 100% · σ_W / μ
Intermediate Precision: RSD_IP(%) = 100% · √(σ²_B + σ²_W) / μ

with μ estimated by the average value of the counts.

Repeatability and intermediate precision are divided by the mean μ to obtain a measure of precision as a percentage of the average value. These measures of precision are typically not provided by standard software packages and should be calculated manually when the two variance components of σ²_W and σ²_B have been determined.

Sometimes, it is better to analyze the precision experiment on the logarithm of the counts, when the distribution in the replicated counts within a run show skewness, as counts often show positive skewness (see Section 10.1).

If the skewness suggests transforming the counts to the logarithmic scale, the measures of precision for the counts itself are estimated in the following way:

Repeatability: RSD_R(%) = 100% · √(exp{σ²_W} − 1)
Intermediate Precision: RSD_IP(%) = 100% · √(exp{σ²_W + σ²_B} − 1)

This calculation assumes that the logarithmically transformed counts are approximately normally distributed. The advantage is that the mean value of the counts no longer plays a role in the calculation of the measures of precision. However, to compare these measures of precision with what can be expected from a Poisson distribution, the mean count is still required to be able to determine the relative standard deviation depicted in Figure 10.4-1.

導師解析 Tutorial Commentary

核心概念解析 Key Concepts

MS_W / MS_B（Within/Between Mean Square, run 內／run 間均方）：ANOVA 拆解變異的兩個核心輸出。MS_W 直接就是 σ²_W 的估計值；MS_B 則同時包含 σ²_W 與「放大 n 倍」的 σ²_B，因此必須經過代數處理才能單獨萃取出 σ²_B。

對數尺度分析：當計數呈現正偏態（positive skewness）時，改在 log(count) 尺度上做 ANOVA 較符合常態假設；但代價是必須額外用平均值 μ 才能與 Poisson 理論 RSD 做比較。

比喻說明 Analogy

可以把 σ²_W 和 σ²_B 想成量測身高時的兩層誤差：σ²_W 是「同一把尺、同一個人，重複量三次」的誤差（尺本身的雜訊）；σ²_B 則是「換一把尺、換一個人來量」所多出來的額外落差。MS_B 這個統計量之所以要扣掉 σ²_W 再除以 n，是因為每次「換人換尺」的觀測值，其實已經內含了「同一把尺重複量」的雜訊，必須先拆分乾淨才能單獨看出「換人換尺」本身帶來多少額外變異。

重點提示 Key Notes

當每個 run 的重複次數不相等時，MS_B 的公式從 n·σ²_B + σ²_W 變成 c·σ²_B + σ²_W，其中 c 是一個依樣本數不平衡程度而定的加權係數。這提醒品保人員：若驗證實驗設計時各 run 的重複數不一致（例如某天因樣品不足只做了 3 重複而非 4 重複），必須用不平衡 ANOVA 公式，不能直接套用平衡設計的簡化公式，否則 σ²_B 估計值會有偏誤。

公式與計算 Formula

計數尺度（Counts scale）之精密度量測：

Repeatability:           RSD_R(%)  = 100% · σ_W / μ
Intermediate Precision:  RSD_IP(%) = 100% · √(σ²_B + σ²_W) / μ

對數計數尺度（Log-counts scale）之精密度量測：

Repeatability:           RSD_R(%)  = 100% · √(exp{σ²_W} − 1)
Intermediate Precision:  RSD_IP(%) = 100% · √(exp{σ²_W + σ²_B} − 1)

變數定義：

  • σ²_W = run 內變異數成分（由 MS_W 直接估計）
  • σ²_B = run 間變異數成分（由 MS_B 扣除 σ²_W 後再除以 n 推算）
  • μ = 計數平均值（僅計數尺度公式需要）
  • exp{} = 自然指數函數，用於將對數尺度變異數換算回原始比例尺度的相對變異

10.4.1.1 Analysis of the Counts 計數尺度分析

原文內容 Original Text

Using the count data from Table 10.4-1, the mean value is estimated at 68.375 CFUs and the mean squares (rounded to two decimals) are determined at MS_B = 86.21 and MS_W = 38.00. The variance component for the between-run variability is then equal to σ²_B = 12.0536 (not using rounded mean squares). This results in the following values for the measures of precision:

RSD_R(%) = 9.02%
RSD_IP(%) = 10.35%

導師解析 Tutorial Commentary

核心概念解析 Key Concepts

手算流程示範：本節是唯一一段完整攤開「從均方到 RSD%」實際計算路徑的段落，讀者可以拿計算機依樣操作以驗證自己是否理解公式。

比喻說明 Analogy

把 μ = 68.375、MS_B = 86.21、MS_W = 38.00 想成一份「體檢報告的三個關鍵數字」：平均值告訴你「這批菌落大概多少」，MS_W 告訴你「同一天同一人量測本身的雜訊」，MS_B 告訴你「不同天不同人量測後多出來的額外落差」。把這三個數字放進公式，就能一次算出兩種精密度指標，作為方法是否「夠穩」的最終判讀依據。

重點提示 Key Notes

原文特別註明 σ²_B = 12.0536「is not using rounded mean squares」——這是一個重要的計算細節提醒：中間計算步驟（MS_B、MS_W）應保留足夠有效位數，只有最終呈現的 RSD% 才適合四捨五入，否則多次四捨五入的誤差會逐步放大，導致最終精密度數字失真。

公式與計算 Formula

代入計算（Table 10.4-1 計數資料，n = 4 重複/run）：

μ = 68.375
MS_B = 86.21,  MS_W = 38.00
σ²_B = (MS_B − MS_W) / n = (86.21 − 38.00) / 4 ≈ 12.0536  （以未捨入均方精算）
σ²_W = MS_W = 38.00

RSD_R(%)  = 100% × √38.00 / 68.375        ≈ 9.02%
RSD_IP(%) = 100% × √(12.0536 + 38.00) / 68.375 ≈ 10.35%

實務應用 Practical Application

CDMO 在撰寫方法驗證報告時，應把「未捨入的中間值」與「最終呈現的 RSD%」都納入原始數據附件，方便日後稽核人員重新演算並確認結果的可追溯性（traceability），這也符合 GDocP 對計算過程完整記錄的要求。

10.4.2 Generalized Linear Mixed Effects Model 廣義線性混合效應模型

原文內容 Original Text

Assuming the counts in Table 10.4-1 within a run would follow the Poisson distribution, a generalized linear mixed effects analysis could be used. In such a model, it is assumed that there exists a latent variable z_i for run i that affects the mean count in the run. The expected count given this latent variable z_i is then formulated as:

𝔼(y_ij | z_i) = exp{α + z_i}

Where:

  • λ_α = exp{α}: the median count over all possible runs for the spike level used in the precision experiment
  • z_i = latent variable for run i, often assumed normally distributed with zero mean and variance τ²
  • α = intercept

The variance τ² for the latent variable z_i would represent the variability between the runs in the logarithmic scale.

Based on this Poisson model, the measures of precision for the counts in their original scale can be calculated as follows:

Repeatability: RSD_R(%) = 100% · exp{−α/2}
Intermediate Precision: RSD_IP(%) = 100% · [exp{−α − τ²/2} + exp{τ²} − 1]^(1/2)

Fitting the GLMM may not be common in all general-purpose statistical software packages, but it could be determined with [R] and SAS®. In SAS®, the analysis can be determined by the procedure GLIMMIX. Such packages provide the estimates for α and τ², from which the measures of precision can be manually determined (by using the formulas above). The TriMSA software provides these measures of precision directly in the output of the analysis.

The GLMM analysis on the data of Table 10.4-1, gives an estimate of α that is equal to 4.2248 and an estimate of τ² equal to 0.000378. In case the variance component τ² is equal to zero, the intermediate precision becomes equal to the repeatability, but here the intermediate precision is slightly larger than the repeatability. Thus, the two measures of precision are now (manually) estimated at:

Repeatability: RSD_R(%) = 12.09%
Intermediate Precision: RSD_IP(%) = 12.25%

These values are slightly larger than the calculations from ANOVA, because the Poisson distribution fixes the repeatability to 100%/√λ, with λ as the median value. Thus, the repeatability is now exactly equal to the relative standard deviation of the Poisson distribution for an average of λ = 68.36 (= exp{4.2248}), since a Poisson distribution was assumed for the replicated counts conditionally on the executed run. Thus, the repeatability is what we can be expected from Poisson distribution, and the intermediate precision is only slightly higher than the repeatability. Overall, the measures of precision are satisfactory.

導師解析 Tutorial Commentary

核心概念解析 Key Concepts

Latent Variable z_i（潛在變數）：代表每個 run 本身無法直接觀察、但會系統性拉高或拉低該 run 平均計數的隨機效應，假設服從常態分布、平均為 0、變異數為 τ²。

GLMM（廣義線性混合效應模型）：結合「Poisson 分布描述 run 內計數」與「常態分布描述 run 間潛在變數」的兩層模型結構，比 ANOVA 多了一個明確的分布假設，因此能直接把 Repeatability 綁定在 Poisson 理論值上。

α（截距）：exp(α) 即為所有可能 run 的中位數計數（median count），是模型估計出的「典型菌落濃度」。

比喻說明 Analogy

GLMM 的兩層結構像是「連鎖店業績分析」：每家分店（run）當天的業績（計數）本身有一定隨機波動（Poisson 雜訊，這是 Repeatability 的來源），但不同分店之間又有各自的「基本體質」差異（latent variable z_i，這是額外疊加的 run 間變異，也就是 τ²）。GLMM 同時對這兩層變異建模，比單純看「所有分店業績的變異數」（ANOVA 的做法）更貼近資料實際生成的機制。

重點提示 Key Notes

GLMM 算出的 Repeatability（12.09%）明顯高於 ANOVA 算出的 9.02%，但這並非模型「更差」，而是因為 GLMM 把 Repeatability 直接鎖定在 Poisson 理論公式 100%/√λ 上（λ = 68.36 時剛好對應約 12.1%），是一種「符合 Poisson 假設下的理論值」；而 ANOVA 的 9.02% 則是純粹由實驗資料的實際離散程度算出，不受 Poisson 假設限制。兩者的差異本身就是判斷「資料是否真的服從 Poisson 分布」的線索——若兩者差距很大，代表資料可能出現 overdispersion（過度離散）或 underdispersion（離散不足），值得進一步查核。

公式與計算 Formula

GLMM 模型結構：

E(y_ij | z_i) = exp{α + z_i}
z_i ~ Normal(0, τ²)

由 α、τ² 換算精密度：

Repeatability:           RSD_R(%)  = 100% · exp{−α/2}
Intermediate Precision:  RSD_IP(%) = 100% · [ exp{−α − τ²/2} + exp{τ²} − 1 ]^(1/2)

變數定義：

  • α = 截距，exp(α) 為所有 run 的中位數計數
  • τ² = run 間潛在變數 z_i 的變異數（對數尺度上的 run 間變異）

代入 Table 10.4-1 資料之估計結果：

α̂ = 4.2248,  τ̂² = 0.000378  →  λ = exp(4.2248) ≈ 68.36

RSD_R(%)  = 100% × exp(−4.2248/2)                                   ≈ 12.09%
RSD_IP(%) = 100% × [ exp(−4.2248 − 0.000378/2) + exp(0.000378) − 1 ]^0.5 ≈ 12.25%

10.4.3 Comparing Precision of the Alternative/Rapid Microbiological Method with the Conventional Method 與傳統培養法之精密度比較

原文內容 Original Text

In addition to the data collection for the AMM/RMM in Table 10.4-1, precision data was also collected for the CMM so the AMM/RMM could be compared with the CMM. It is assumed here that the data was collected on other days and possibly with analysts other than those for the AMM/RMM. This means that the runs for the CMM are runs other than those for the AMM/RMM. The data for the CMM are presented in Table 10.4.3-1.

See Table 10.4.3-1 below.

It should be noted that comparing precision measures between the AMM/RMM and CMM often requires an unrealistic large number of test samples. Table 10.4.3-2 shows the sample size per microbiological method (i.e., replicated counts when all data is collected within a single run) for traditional hypothesis-testing, assuming a specific ratio between the variance components σ²_A/σ²_C (type 1 error rate is 0.05 and the power is 0.80). Table 10.4.3-2 clearly shows that an increase in the variance of less than 50% from the CMM to the AMM/RMM is difficult to conduct for each species separately. Thus, most of the time, traditional hypothesis-testing would show that there is no difference in variance components. On the other hand, non-inferiority testing would typically lead to a wide confidence interval that would hardly ever satisfy a non-inferiority margins of 0.7 when the variance of the CMM is compared to the variance of the AMM/RMM or, alternatively, margins of 1.3 if the variance of the AMM/RMM is divided by the variance of the CMM. It is therefore recommended to either accept less strict non-inferiority margins on the ratio of variances or to compare the two microbiological methods more qualitatively. A non-inferiority margin of 2 on the ratio σ²_A/σ²_C (or 0.5 on the ratio σ²_C/σ²_A) may be considered reasonable, since it leads to a non-inferiority margin of approximately 0.7 on the ratio of precisions σ_C/σ_A and seems practical considering the information in Table 10.4.3-2.

See Table 10.4.3-2 below.

It is common to compare the precision estimates of the AMM/RMM and CMM in a ratio where the precision of the CMM is put in the denominator. This means that a non-inferiority margin becomes a value above one, like 1.3, instead of a value below one, like 0.7, which has been used for other validation parameters so far. Indeed, when the precision of the AMM/RMM gets too large, the AMM/RMM may be considered inferior to the CMM and the ratio σ_A/σ_C becomes too far beyond one. It is important to realize that 0.7 and 1.3 are not the same non-inferiority margins in case the ratio is reversed and the precision of the AMM/RMM is put in the denominator. A non-inferiority margin of 1.3 on the ratio σ_A/σ_C would lead to a non-inferiority margin of 0.769 (=1/1.3) on the ratio σ_C/σ_A. Finally, putting a non-inferiority margin on the ratio of the precisions is not the same as putting a non-inferiority margin on the ratio of the variances (i.e., the ratio of squared precisions) as discussed in previous paragraph. Indeed, a non-inferiority margin of 1.3 on the ratio σ_A/σ_C is the same as putting a non-inferiority margin of 1.69 on the ratio σ²_A/σ²_C or 0.592 on the ratio σ²_C/σ²_A.

The approach to compare the precision of the AMM/RMM with the precision of the CMM again depends on the distributional assumptions. If it is assumed that the counts per run are Poisson-distributed, the repeatability is determined by the mean count exp{α}. Comparing this parameter between the AMM/RMM and CMM is then better done in an accuracy experiment as discussed in Section 10.1. Thus, for the GLMM approach, it would not make sense to compare the repeatability between the microbiological methods if an accuracy study is also conducted. The only comparison between the AMM/RMM and the CMM that would possibly make sense is the comparison of the parameter τ² that describes the between-run variability. However, a difference in τ² between the two microbiological methods may not have a strong effect on the ratio of the intermediate precision, since it also contains the within-run variability. To illustrate this, the ratio 100% · RSD_IP^A(%)/RSD_IP^C(%) of the two intermediate precisions for the microbiological methods can be visualized as a function of the ratio 100% · τ_A/τ_C for different values of the mean count exp{α}. Here, it is assumed that both microbiological methods have the same mean count (or repeatability). Figure 10.4-1 shows that when the standard deviation τ_A of the AMM/RMM is twice as large as the standard deviation τ_C of the CMM (and the variance is thus four times larger), the intermediate precision of the AMM/RMM is only 31% (or much less) larger than the intermediate precision of the CMM for enumerations less than 90 CFU. When the repeatability is large, the repeatability dominates the intermediate precision, and a strong difference in variance components (as a factor 4, as noted previously) is not picked up. Thus, to understand the differences between the two microbiological methods when the Poisson distribution is used, comparing the two standard deviations τ_A and τ_C from the GLMM analysis is recommended.

If the replicates within the runs of the precision experiment do not demonstrate a Poisson distribution, the counts or the log counts with the ANOVA can be modelled, assuming that the counts follow a normal distribution. The decision not to use the Poisson distribution is mainly driven by a violation of the relation between the mean and the variance of the replicated counts within runs (see also Section 10.1.3). When the variances for the runs deviate from the means of the runs, an alternative distribution to the Poisson distribution should be used. This evaluation is not always easy to conduct due to the relatively small number of replicates per run, and it may be necessary to do it qualitatively. If the Poisson distribution is rejected and the normal distribution describes either the counts or log counts properly for each microbiological method, which can be evaluated through a residuals plot (Figure 10.4-2) after conducting an ANOVA, the ANOVA approach can be used to compare both the repeatability and the intermediate precision.

10.4.3.1 ANOVA Method on the Counts 計數尺度之 ANOVA 比較法

原文內容 Original Text

To compare the measures of precision for AMM/RMM with CMM, the values for repeatability and intermediate precision for the two methods separately can be calculated as described in Section 10.4.1 (using counts). The calculation of the two ratios RSD_R^A(%)/RSD_R^C(%) and RSD_IP^A(%)/RSD_IP^C(%) are then straightforward to calculate.

Applying the ANOVA approach to the count data in Table 10.4.3-1 for the CMM results in a mean square MS_B = 64.375 and MS_W = 157.125. The variance component for the between-run variability is then estimated at σ²_B = 23.19. The mean count was determined at 69.81. Thus, the measures of precision for the CMM are now estimated at RSD_R^C(%) = 11.49% and RSD_IP^C(%) = 13.40%. Comparing the measures of precision of the AMM/RMM with the measures of precision of the CMM, leads to the following ratios (expressed in percentages):

Ratio for Repeatability: 100% · RSD_R^A(%) / RSD_R^C(%) = 78.45
Ratio for Intermediate Precision: 100% · RSD_IP^A(%) / RSD_IP^C(%) = 77.20

Clearly, these ratios show that the estimated precision of the AMM/RMM is less than the estimated precision of the CMM. To better understand this ratio, it is recommended to calculate an upper 95% confidence limit for these two ratios using the logarithmic scale. Unfortunately, confidence intervals on ratios of variance components are mathematically not straightforward, particularly for the intermediate precision.

The variance of a mean square MS in a random effects ANOVA model can be estimated by:

2·MS² / df

with df as the degrees of freedom in the ANOVA table for the specific mean square.

The degrees of freedom of the within-run mean square m(n−1) is equal to the number of runs (m) multiplied with the number of degrees of freedom of (n−1) for the n replicated counts in one run. The asymptotic variance of the logarithmically transformed standard deviation for the within-run variability 0.5·log(MS_W) is then equal to [2m(n−1)]⁻¹. Hence, the asymptotic upper 95% confidence limit for the ratio RSD_R^A(%)/RSD_R^C(%) is then determined by:

ULR = [RSD_R^A(%) / RSD_R^C(%)] · exp{ 1.645 / √(m(n−1)) }

where the uncertainty in the mean count was not taken into account.

For the example data in Table 10.4-1 and Table 10.4.3-1, the degrees of freedom is equal to 24 (= 8 · (4 – 1)) for the within-run mean square for both microbiological methods. The upper 95% confidence limit for the ratio of repeatability is now determined by:

ULR = 109.7%

The estimate for the sum of the two variance components σ²_B + σ²_W is equal to [MS_B + (n−1)MS_W]/n. The estimated variance of this estimator is equal to:

2 · [ MS_B² / df_B + (n−1)² MS_W² / df_W ] / n²

because the two mean squares are independent for balanced data (i.e., the same number of replicates per run).

The degrees of freedom for the mean square between-runs equal the number of runs minus one (df_B = m − 1). The variance of the total variability of within- and between-runs, 0.5·log([MS_B + (n−1)MS_W]/n), is then approximately equal to:

η² = 0.5 · [ MS_B² / df_B + (n−1)² MS_W² / df_W ] / [MS_B + (n−1)MS_W]²

The upper 95% confidence limit for the ratio RSD_IP^A(%)/RSD_IP^C(%) is now determined by:

ULIP = [RSD_IP^A(%) / RSD_IP^C(%)] · exp{ 1.645 · √(η²_A + η²_C) }

Applying these formulas to the observed results, the upper 95% confidence limit for the ratio of intermediate precisions becomes equal to ULIP = 107.6%.

The formulas for the upper 95% control limits of the ratio of repeatability and intermediate precision for the two microbiological methods can be programmed in Excel. The only input that is needed for each microbiological method is the mean, the two mean squares, and their degrees of freedom.

The upper 95% confidence limits for the ratios of both the repeatability and the intermediate precision are less than the non-inferiority limit of 141% (= 100%√2) assuming a non-inferiority margin of 2 for the corresponding variances. Thus, the precision measures of the AMM/RMM is non-inferior to the precision of the CMM when a non-inferiority margin (e.g., 2) is used on the variance for the relative standard deviations.

核心概念解析 Key Concepts

Satterthwaite 型漸近信賴區間：由於變異數比值的信賴區間在數學上並不直觀（不像平均值差異可直接用 t 分布），本節採用「對數轉換 + 漸近常態近似」的技巧：先取 0.5·log(MS) 的變異數（與自由度成反比），再用常態分布反推出上限，最後指數轉換回原始比值尺度。

ULR / ULIP（Upper Limit of Repeatability / Intermediate Precision Ratio）：分別是重複性比值與中間精密度比值的漸近上 95% 信賴上限，用於與預先設定的不劣性界限（如 141%）比較，決定是否宣告 AMM/RMM 精密度不劣於 CMM。

比喻說明 Analogy

可以把整套流程想成「用溫度計量體溫時的兩層修正」：先把原始比值（如 78.45%）看成「單次量測讀數」，但你知道這個讀數本身有不確定性；於是先把它轉換到對數尺度（像是把體溫換算成另一種單位方便統計），套用自由度算出的變異數估計出信心區間寬度，再指數轉換回原始比值尺度，得到「這個讀數最壞可能到多高（上限）」的保守估計——這個上限才是用來跟法規界限比較的正確依據，而非原始點估計值本身。

重點提示 Key Notes

本節的判定邏輯值得特別留意：雖然點估計顯示 AMM/RMM 精密度比值（78.45% / 77.20%）都低於 100%（代表 AMM/RMM 看起來比 CMM 更精密），但正確的統計決策程序仍是計算「上 95% 信賴上限」（109.7% / 107.6%），並將此上限與不劣性界限（141%）比較，而非直接用點估計值判定。這是統計驗證中「用最壞情況（上限）做保守決策」的核心原則，避免因抽樣誤差而過度樂觀地宣稱方法優異。

公式與計算 Formula

均方變異數估計：

Var(MS) = 2·MS² / df

Repeatability 比值之漸近上 95% 信賴限：

ULR = [RSD_R^A(%) / RSD_R^C(%)] · exp{ 1.645 / √(m(n−1)) }

Intermediate Precision 比值之漸近上 95% 信賴限：

η² = 0.5 · [MS_B²/df_B + (n−1)²·MS_W²/df_W] / [MS_B + (n−1)MS_W]²
ULIP = [RSD_IP^A(%) / RSD_IP^C(%)] · exp{ 1.645 · √(η²_A + η²_C) }

變數定義：

  • m = run 數（本例 = 8）；n = 每 run 重複數（本例 = 4）
  • df_W = m(n−1) = run 內均方之自由度（本例 = 8×3 = 24）
  • df_B = m − 1 = run 間均方之自由度
  • 1.645 = 標準常態分布單尾 95% 信心水準對應之臨界值

代入計算：

CMM: MS_B = 64.375, MS_W = 157.125, σ²_B ≈ 23.19, mean ≈ 69.81
RSD_R^C(%)  ≈ 11.49%,   RSD_IP^C(%) ≈ 13.40%

Ratio Repeatability = 78.45%,  Ratio Intermediate Precision = 77.20%
df_W = 8×(4−1) = 24

ULR  = 78.45% × exp{1.645/√24}  ≈ 109.7%
ULIP = 77.20% × exp{1.645×√(η²_A+η²_C)} ≈ 107.6%

非劣性界限（變異數比 2 對應之精密度比）= 100%×√2 ≈ 141%
→ 109.7% < 141% 且 107.6% < 141%  ⇒  判定 AMM/RMM 精密度不劣於 CMM

原文內容 Original Text

Assuming that the counts within the runs are Poisson-distributed and the runs add additional variation to the counts, the same analysis can be used for the CMM as was done for the AMM/RMM. The estimates and standard error for the parameters in the Poisson model for both the AMM/RMM and CMM are shown in Table 10.4.3.2-1.

See Table 10.4.3.2-1 below.

As mentioned earlier, the ratio of the two variance components τ²_A and τ²_C for the between-run variability of the two microbiological methods should be investigated. The estimator of the variance component will be approximated with a chi-square distribution and then using the F-distribution to calculate an upper confidence limit on the ratio of the variance components. This upper limit can then be used to determine non-inferiority if a non-inferiority margin, say 2, is prescribed for the precision experiment.

To approximate the estimators of the variance component with a chi-square distribution, only the degrees of freedom need to be estimated. Making use of the Satterthwaite approach (an approach that is used for t-tests with unequal variances as well), the formula for the degrees of freedom for the estimator τ̂² for the variance component τ² is given by:

df = 2·τ̂⁴ / SE(τ̂²)²

with SE(τ̂²) the standard error of the estimator τ̂².

In practice, such degrees of freedom can sometimes become small when variance components are relatively small, so degrees of freedom will not be accepted less than the degrees of freedom for the between-run variability, which is defined by the number of runs minus one (similar to ANOVA).

導師解析 Tutorial Commentary

核心概念解析 Key Concepts

Satterthwaite 自由度近似法：當某個變異數估計量並非來自標準平衡設計（如 GLMM 的 τ̂²），無法直接查表得知精確自由度時，Satterthwaite 提供一個通用公式，用「估計量本身的平方」與「其標準誤的平方」推算出等效自由度，讓 τ̂² 可以近似套用卡方分布（chi-square distribution）進行後續信賴區間或假設檢定。

下限保護機制：原文特別規定，計算出的 Satterthwaite 自由度不得低於「run 數減一」——這是一個保守的下限保護，避免變異數過小時自由度被低估到不合理程度。

比喻說明 Analogy

Satterthwaite 自由度公式就像是在「合併兩份不同可信度的民調結果」時，估算「這份合併結果相當於問了幾個人」的等效樣本數。當某份民調本身的誤差範圍（標準誤）很大、估計值又小，代表這份資料的「有效訊息量」其實很少，即使表面上收集了很多筆觀測值，統計上能提供的自由度也會被相應壓低。

重點提示 Key Notes

本節與 10.4.3.1 節形成清楚對照：ANOVA 途徑（10.4.3.1）處理的是 σ²_B、σ²_W 這兩個「均方直接可查表得知自由度」的變異數成分；而 GLMM 途徑（10.4.3.2）處理的 τ² 則沒有現成自由度公式，必須靠 Satterthwaite 近似。這提醒實務人員：選擇 GLMM 分析路徑時，除了模型配適本身的複雜度外，後續進行方法間比較（non-inferiority）時的統計計算也會更複雜，需要更謹慎的軟體驗證與人員訓練。

公式與計算 Formula

Satterthwaite 自由度公式：

df = 2·τ̂⁴ / SE(τ̂²)²

變數定義：

  • τ̂² = run 間變異數成分 τ² 的估計值
  • SE(τ̂²) = τ̂² 估計量的標準誤
  • 下限規則：計算出的 df 不得低於（run 數 − 1）

代入 Table 10.4.3.2-1 之估計值：

AMM/RMM:  α̂ = 4.2248 (SE=0.02248),  τ̂² = 0.000378 (SE=0.002022)
CMM:      α̂ = 4.2441 (SE=0.02960),  τ̂² = 0.003408 (SE=0.003468)

df_A = 2×(0.000378)² / (0.002022)²  ≈ 0.070   → 因小於 (m−1)=7，取 df_A = 7（套用下限規則）
df_C = 2×(0.003408)² / (0.003468)²  ≈ 1.92    → 因小於 (m−1)=7，取 df_C = 7（套用下限規則）

（註：上列代入計算為依原文公式推導之示範數值，原文本身未列出最終 df 數值，僅說明計算原則與下限保護規則。）

本節重點回顧 Section Summary

  • 精密度由 Repeatability（run 內變異）與 Intermediate Precision（run 內＋run 間變異）兩個 RSD% 指標共同描述，ANOVA 途徑透過 MS_W、MS_B 拆解變異成分，計數尺度與對數尺度通常結果相近，可用殘差機率圖判斷何者較貼近常態假設
  • 若 run 內計數符合 Poisson 分布，GLMM 途徑可將 Repeatability 直接鎖定在理論值 100%/√λ 上，其潛在變數 z_i（變異數 τ²）描述 run 間額外變異；GLMM 與 ANOVA 結果的落差本身即為判斷 Poisson 假設是否成立的診斷線索
  • AMM/RMM 與 CMM 的精密度比較受限於樣本數需求（Table 10.4.3-2 顯示差異 25–50% 需要數百組樣本），實務上建議採用較寬鬆的不劣性界限（如變異數比 2，對應精密度比約 141%）或搭配 GLMM 的 τ 比較
  • 務必區分「精密度比值的非劣性界限」與「變異數比值的非劣性界限」——兩者呈平方關係（如 1.3² = 1.69），且比值反轉後界限也不是簡單倒數（1.3 反轉後為 0.769，而非 0.7）
  • Satterthwaite 自由度近似法用於處理 GLMM 中沒有現成查表自由度的變異數成分（如 τ²），並設有「不低於 run 數−1」的下限保護規則
